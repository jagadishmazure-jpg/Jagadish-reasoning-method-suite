# Security policy

This repo contains no real data, no credentials, and no network calls. If
you find a real name, real personal data, or a secret in it, please report
it via a private channel to the repo owner rather than opening a public
issue.

Supported: the current `main` branch only. This is a scaffold (not yet
pushed); the workflow file in `.github/workflows/ci.yml` has not run, so
no CI status is claimed.
